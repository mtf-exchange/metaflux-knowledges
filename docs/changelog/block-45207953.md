# Activation notice: block 45,207,953 {#activation-notice--block-45207953}

This page records what changed on chain 114514 at block 45,207,953.

:::info
In effect since block 45,207,953. Node 0.9.20 swapped in at block 45,207,952 (2026-10-30 07:55 UTC), and the rules below turned on one block later. No gateway or indexer release rode this window.

`{"type":"account_state","address":"0x…"}` returns the current `height`. Use it to check where the chain is.
:::

The pin is one block above the swap. The outgoing node commits block 45,207,952 and then halts, so that block still ran the old rules. The new rules apply from the first block after it.

## Negative equity is backstopped and refused new exposure {#negative-equity}

Before the height the node read an account under water on a dust position as safe, and let it add to that position. Measured on chain 114514: a wallet at negative equity added to one position 628 times in four weeks, and four wallets sat at negative equity with no position.

| Case | Before the height | Now |
|---|---|---|
| An order that opens or extends a position when free collateral is negative, and the whole-USDC initial-margin increase rounds to zero | admitted | refused, `MARGIN_INSUFFICIENT`. See [the pre-trade gate](../concepts/margin-modes.md#initial-margin-pre-trade-gate) |
| An account with negative `account_value` whose maintenance margin rounds to zero | idle, [`tier`](../api/rest/info/account.md#account_state) `"Safe"` | backstopped, `tier` `"T3"`. See [tiered liquidation](../concepts/tiered-liquidation.md#how-tiers-are-computed) |
| The maintenance margin of an account with several cross positions | each position floored to whole USDC, then summed | summed, then floored once. It can read up to one USDC per position higher |
| An account with negative `account_value` and no position | the deficit stayed on the account | the deficit moves to the insurance fund, then to the treasury queue, and `account_value` reads `0`. No winner is haircut for it |
| A cross spot-margin position on an account with negative `account_value` | liquidated only when the maintenance margin was not zero | liquidated |
| The maintenance line of an isolated position | priced on its entry notional | priced on the greater of its entry notional and its notional at the mark, as a cross position is |

Measured after the swap: the four flat wallets read `account_value` `0` and `tier` `"Safe"` on their first liquidation pass.

## A dropped notice no longer follows a successful write {#duplicate-seal}

Before the height, almost every action committed twice: the leader of the next block sealed its own gossiped copy of an action the parent block already carried, and the chain dropped that copy as a nonce replay. The sender then received a `dropped at commit: nonce already used, or below the replay window` notice on the notifications channel after a write that had succeeded. Measured before the swap: about 85 % of committed actions were such drops. Measured after: 0.8 %, all of them real nonce collisions from the sender.

A leader now skips an action whose `(sender, nonce)` is already in a block it extends. Nothing changes on the wire: the first copy commits as before, and the notice is sent only when a write is really dropped.
