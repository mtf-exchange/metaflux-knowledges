# Activation notice: block 44,478,893 {#activation-notice--block-44478893}

This page records what changed on chain 114514 at block 44,478,893.

:::info
In effect since block 44,478,893. Node 0.9.18 swapped in at block 44,478,892 (2026-10-29 08:00 UTC), and every rule below turned on one block later. No gateway or indexer release rode this window.

`{"type":"account_state","address":"0x…"}` returns the current `height`. Use it to check where the chain is.
:::

Every change below moves at one height, so the chain gains one boundary for the whole release.

The pin is one block above the swap. The outgoing node commits block 44,478,892 and then halts, so that block still ran the old rules. The new rules apply from the first block after it.

## Deployer markets {#deployer-markets}

| Surface | Before the height | Now |
|---|---|---|
| [`mark_source`](../api/rest/info/perpetuals.md#markets_meta) on a market priced by a deployer push | one of the three core modes | `"deployer_oracle"`: the mark equals the pushed price, and the book does not move it. See [mark prices](../concepts/mark-prices.md) |
| [`register_asset`](../api/rest/exchange/deploy-perp.md) `max_leverage` | `1`-`50` | `1`-`100`. A value above 50 also needs a validator vote that raises the per-market limit |
| [`mip3_set_oracle_px`](../api/rest/exchange/deploy-perp.md#mip3_set_oracle_px) outside the move band | refused: `oracle px <px> outside the ±10% move band` | accepted at the band edge. The band is ±min(10 %, 1/(2L)), where L is the highest leverage the market admits |
| A staking withdraw or undelegate that takes a deployer below the bond floor while its dex has a market | accepted | refused: `deployer bond is locked while the dex has a market` |
| A governance `listing` that names an existing `<dex>:<suffix>` market | refused | raises the market's `sz_decimals` and rescales every resting order and position |
| A liquidation deficit on a deployer market | protocol shortfall | stays inside that market's dex. See [tiered liquidation](../concepts/tiered-liquidation.md) |
| `min_order` on `markets_meta` and the contract specifications | could show a value larger than one lot that no check applied | equals `step_size`, one lot |
